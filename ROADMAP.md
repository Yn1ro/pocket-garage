# Product Roadmap — «Карманный гараж»

Дорожная карта разработки, пилотирования и масштабирования цифровой экосистемы для автовладельцев и СТО.

---

## Фаза 1: Исследование и Технический Проект (MVP Architecture) - [Done]
- [x] **Product Discovery:** Формулирование проблемы, исследование рынка СТО/запчастей в РФ, определение ЦА и Персон.
- [x] **Requirements & Business Analysis:** Разработка функциональных (FR) и нефункциональных (NFR) требований, сценариев Use Case (UC-001).
- [x] **Data Engineering:** Проектирование логической модели данных (PostgreSQL, 8 ключевых сущностей, DI-правила).
- [x] **System Architecture & API:** Разработка C4 Model (Context & Container), проектирование асинхронной шины Apache Kafka и контракт REST API (OpenAPI 3.0 / Swagger).

---

## Фаза 2: Прототипирование и MVP Разработка - [In Progress]
- [ ] **System Analysis & Integrations (Хард-скиллы):**
  - [ ] Составление Postman-коллекций для тестирования эндпоинтов Vehicle API.
  - [ ] Спецификация обработки ошибок (HTTP Status Codes & Error Handling).
  - [ ] Проектирование схемы интеграции с внешними сервисами декодирования VIN.
- [ ] **UI/UX Design (Figma):**
  - [ ] Прототип экрана «Цифровой гараж» и карточки ТС.
  - [ ] Экран поиска СТО на карте и формы онлайн-записи.
- [ ] **Core Backend Services:**
  - [ ] Микросервис `Vehicle Service` (управление гаражом, декодирование VIN).
  - [ ] Микросервис `User & Auth Service` (JWT-аутентификация).
  - [ ] Настройка API Gateway (Nginx/Kong) и Redis (кэширование слотов и VIN-данных).

---

## Фаза 3: Пилотный Запуск 
- [ ] **B2B Onboarding:** Подключение 5-10 локальных независимых СТО к веб-кабинету партнера.
- [ ] **User Acquisition:** Привлечение первых 1 000 автовладельцев через региональные автосообщества.
- [ ] **Pilot Metrics Validation:**
  - [ ] Замер конверсии из поиска СТО в подтвержденную запись.
  - [ ] Валидация юнит-экономики (комиссия 3-5% с чека СТО).
  - [ ] Оценка Retention Rate 30-го дня для модуля «Цифровой гараж».

---

## Фаза 4: Расширение функционала и Региональный рост
- [ ] **AI Diagnostic Assistant (PoC):** Распознавание значков приборной панели по фото (Computer Vision).
- [ ] **Marketplace & P2P:** Запуск модуля «Барахолка» (продажа б/у запчастей и шин) и P2P-чатов.
- [ ] **FinTech & InsurTech:** Интеграция агрегатора ОСАГО/КАСКО и встроенная проверка/оплата штрафов.

---

## Фаза 5: Федеральный Охват и EV Track 
- [ ] Масштабирование сервиса на миллионники РФ и рынки СНГ.
- [ ] **EV Track (Электромобили):** Карта ЭЗС, мониторинг состояния батареи (SoH) и учет зарядок.
