#  Product Roadmap — «Карманный гараж»

Дорожная карта разработки, пилотирования и масштабирования цифровой экосистемы для автовладельцев и СТО.

---

##  Фаза 1: Исследование и Технический Проект (MVP Architecture) — [Done]
- [x] **Product Discovery:** Формулирование проблемы, исследование рынка СТО/запчастей в РФ, определение ЦА и Персон.
- [x] **Requirements & Business Analysis:** Разработка функциональных (FR) и нефункциональных (NFR) требований, сценариев Use Case (UC-001).
- [x] **Data Engineering:** Проектирование логической модели данных (PostgreSQL, 8 ключевых сущностей, DI-правила).
- [x] **System Architecture & API:** Разработка C4 Model (Context & Container), проектирование асинхронной шины Apache Kafka и контракт REST API (OpenAPI 3.0 / Swagger).

---

##  Фаза 2: Прототипирование и MVP Разработка — [In Progress]
- [ ] **UI/UX Design (Figma):**
  - [ ] Прототип экрана «Цифровой гараж» и карточки ТС.
  - [ ] Экран поиска СТО на карте и онлайн-записи.
  - [ ] Каталог запчастей с фильтрацией по VIN.
- [ ] **Core Backend Services:**
  - [ ] Микросервис `Vehicle Service` (декодирование VIN, управление авто).
  - [ ] Микросервис `User & Auth Service` (JWT, аутентификация).
  - [ ] Интеграция API Gateway (Kong/Nginx) и Redis (кэширование VIN-запросов).
- [ ] **AI Assistant (PoC):**
  - [ ] Разработка модуля компьютерного зрения для распознавания значков/ошибок на приборной панели по фото.
  - [ ] Кэширование базы кодов OBD-II для офлайн-доступа.

---

##  Фаза 3: Пилотный Запуск (г. Усинск, Республика Коми) — [Q3 2026]
- [ ] **B2B Onboarding:** Проведение переговоров и подключение 5–10 локальных независимых СТО.
- [ ] **User Acquisition:** Привлечение первых 1 000 активных пользователей через автоклубы и локальные сообщества.
- [ ] **Pilot Metrics Validation:**
  - [ ] Проверка конверсии из просмотра СТО в запись через приложение.
  - [ ] Тестирование монетизации (сбор 3-5% комиссии с чека СТО).
  - [ ] Оценка Retention Rate 30-го дня для цифрового гаража.

---

##  Фаза 4: Региональное Масштабирование (Республика Коми и Северо-Запад) — [Q4 2026 - Q1 2027]
- [ ] **B2B Expansion:** Подключение сетевых автосервисов (Fit Service и др.).
- [ ] **Marketplace & P2P:** Запуск модуля «Барахолка» (продажа б/у запчастей и шин с безопасной сделкой) и локальных чатов.
- [ ] **FinTech & InsurTech Integration:**
  - [ ] Встроенный сканер и оплата штрафов ГИБДД.
  - [ ] Подключение агрегатора ОСАГО/КАСКО (партнерская комиссия).
  - [ ] Кнопка SOS (вызов эвакуатора и помощь на дороге).

---

##  Фаза 5: Федеральный Охват и СНГ + EV Track — [2027+]
- [ ] Выход на федеральный уровень и рынки стран СНГ.
- [ ] **EV Track (Электромобили):** Специализированный функционал для владельцев электрокаров (карта ЭЗС, мониторинг здоровья батареи, учет зарядок).
